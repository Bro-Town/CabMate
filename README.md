# CabMate

A live driver display for **Train Sim World 7**. See your speed, braking advice, signals, speed limits and the next station on your phone, tablet or a second screen while you drive.

## Download

Get **CabMate.exe** from the [latest release](https://github.com/Bro-Town/CabMate-Releases/releases/latest).

CabMate updates itself: when a new version is out it asks when you start it, and you choose Update now or Later.

## Before you start

Train Sim World 7 needs the `-HTTPAPI` launch option so CabMate can read it.

- **Steam:** Library → right-click Train Sim World 7 → Properties → Launch Options → type `-HTTPAPI`
- **Epic Games:** Library → three dots on Train Sim World 7 → Manage → turn on Launch Options → type `-HTTPAPI`

Restart the game afterwards. CabMate works with the PC versions of the game on Steam and Epic Games.

## Using it

1. Run **CabMate.exe**. It opens in your browser and sits in the tray by the clock.
2. To use your phone or tablet, choose **Allow phones and tablets** and pick **Private networks** when Windows asks. Then scan the QR code.
3. Get in the driver's seat.

CabMate stores nothing, sends nothing to the internet except checking for updates, and has no accounts. Only devices on your own network can open it.

Windows may say the app is from an unknown publisher the first time. Choose **More info → Run anyway**.
